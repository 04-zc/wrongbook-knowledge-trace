# 错题本知识溯源整理助手 · 录屏测试流程

> 适用版本：commit `5ce5855`  
> 预计时长：25–35 分钟  
> 建议顺序：按本文档从上到下录制，功能依赖关系是线性的

---

## 0. 录制前准备（不在录屏内）

```powershell
# 1. 启动服务
双击 启动错题本.bat

# 2. 建议先清理浏览器缓存，避免看到旧界面
#    打开 http://localhost:5000 后按 Ctrl+Shift+R
```

**录制前必须确认的三件事：**

| 项目 | 检查方式 |
|---|---|
| 大模型 API Key 已配置 | 右上角「模型与 OCR 配置」里能看到 Key |
| OCR 已安装 | 配置页里 OCR 开关可正常显示 |
| 有一个可用的测试账号 | 建议专门建 `demo` / `demo123` 用于录制 |

> ⚠️ 若 Key 未配置，第 8、9 节的 AI 功能会弹提示框而不是生成内容。**建议先配好再录。**

## 3. 错题录入 · 三种方式（约 6 分钟）

> 入口现在是「先选方式」的卡片页，这是重点。

| 步骤 | 操作 | 预期结果 |

| 3.1.2 | 点「手动输入」 | 进入表单，右上角出现「返回」按钮 |

### 3.2 拍照输入

| 步骤 | 操作 | 预期结果 |

## 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 界面是旧样式 / 功能不对 | Service Worker 缓存 | **Ctrl+Shift+R** 硬刷新 |
| AI 功能只弹配置提示 | 未填 API Key | 右上角「模型与 OCR 配置」填入 |
| 拍照识别无结果 | PaddleOCR 未安装 / 已关闭 | 配置页开启 OCR，或改用文件上传演示 |
| 点按钮没反应 | 弹窗遮罩挡住了 | 按 **Esc** 或点遮罩关闭当前弹窗 |
| 导入 PDF 失败 | 文件是扫描版且 OCR 不可用 | 换一个文字版 PDF |
