# 错题本知识溯源整理助手 · 功能模块说明

> 版本：v3.1
> 文档类型：系统功能模块说明

---

## 1. 系统概述

本系统是一套面向个人学习者的本地错题管理与知识溯源工具。系统通过 OCR、PDF/Word 解析、大模型分析、知识树、薄弱分析和复习计划，实现从“记录错题”到“定位薄弱知识点”的完整闭环。

核心目标：

```text
错题录入 → 知识点识别 → 知识溯源 → 薄弱分析 → 复习计划 → 掌握反馈
```

## 2. 技术架构

### 2.1 总体架构

```text
+--------------------------------------------------+
|                    浏览器端                       |
|  Vue 3 + Axios + ECharts + KaTeX                  |
+------------------------+-------------------------+
                         | HTTP / JSON
+------------------------v-------------------------+
|                    Flask 后端                     |
|  账号 / 错题 / 知识树 / 溯源 / 复习 / 报表         |
|  OCR / PDF解析 / Word解析 / 大模型调用             |
+------------------------+-------------------------+
                         | SQLAlchemy
+------------------------v-------------------------+
|                 SQLite 本地数据库                  |
+--------------------------------------------------+
```

### 2.2 技术选型

| 模块 | 技术 | 说明 |
|---|---|---|
| 前端框架 | Vue 3 | 响应式页面，无构建工具 |
| HTTP 请求 | Axios | 前后端数据交互 |
| 图表 | ECharts | 树图、旭日图、折线图、柱状图、环形图 |
| 公式渲染 | KaTeX | LaTeX 公式实时渲染 |
| 后端框架 | Flask | 提供 REST API |
| ORM | SQLAlchemy | 数据模型与数据库访问 |
| 数据库 | SQLite | 本地单文件存储 |
| OCR | PaddleOCR | 图片与扫描版 PDF 文字识别 |
| 文档解析 | python-docx / PyMuPDF | Word 与 PDF 文本提取 |
| 大模型 | DeepSeek / 通义千问 | 知识点推荐、溯源、例题、解答 |

## 4. 用户账号与数据隔离

### 4.1 功能说明

- 用户名与密码仅支持英文字母和数字。
- 密码使用哈希存储。
- 每个用户拥有独立的学科、知识点、错题、复习记录和配置。
- 支持改名、修改密码、重置密码和删除账号。

### 4.2 主要接口

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/auth/register` | POST | 注册 |
| `/api/auth/login` | POST | 登录 |
| `/api/auth/logout` | POST | 退出 |
| `/api/auth/me` | GET | 当前用户 |
| `/api/auth/rename` | POST | 修改账号 |
| `/api/auth/change_password` | POST | 修改密码 |
| `/api/auth/reset_password` | POST | 重置密码 |
| `/api/auth/account` | DELETE | 删除账号 |

## 5. 错题录入模块

### 5.1 手动录入

支持字段：

- 学科
- 题干文本
- 题干图片
- 选项
- 正确答案
- 学生答案
- 解析
- 错误原因
- 状态
- 关联知识点

题干支持 LaTeX 公式，输入后实时渲染。

### 5.2 拍照 OCR

流程：

```text
上传/拍摄图片 → PaddleOCR → 文本清洗 → 回填题干
```

OCR 参数支持：

- 识别语言
- 方向识别
- 置信度阈值

### 5.3 PDF / Word 导入

流程：

```text
上传文件 → 文本提取 / OCR → 自动分题 → 预览修改 → 确认入库
```

支持格式：

- PDF
- DOC
- DOCX

## 7. 知识树模块

### 7.1 结构

知识树为多层级结构：

```text
学科
├── 一级知识点
│   ├── 二级知识点
│   │   └── 三级知识点
│   └── 二级知识点
└── 一级知识点
```

### 7.2 功能

- 新增一级知识点
- 添加子知识点
- 删除知识点及子树
- 搜索知识点并自动定位
- 逐层展开目录
- 查看知识点详情

知识树只保存简短名称，详细内容存放在知识点详情和知识库中。

## 8. 知识溯源模块

### 8.1 AI 溯源

输入：

- 题干
- 正确答案
- 学生答案
- 解析
- 错误原因

输出：

```text
错误表象 → 直接知识点 → 前置知识点 → 根本原因
```

### 8.2 用户确认

- AI 推荐的知识点默认不直接写入知识树。
- 用户勾选后才生成知识溯源思维导图。
- 导图节点可增删、保存和重新打开。

### 8.3 本地反馈学习

系统记录：

- 用户确认的知识点
- 用户删除的 AI 推荐知识点

后续推荐会自动进行置信度加减权，不会影响其他用户。

## 9. 薄弱分析模块

### 9.1 薄弱指数算法

```text
薄弱指数 =
    错题数量归一值 × 0.4
  + 累计错误次数归一值 × 0.3
  + 时间衰减归一值 × 0.2
  + 近 7 天重复错误归一值 × 0.1
```

最终换算为 0～10。

### 9.2 时间衰减

错误发生时间越早，权重越低：

```text
衰减值 = e^(-距离今天的天数 / 30)
```

### 9.3 展示内容

- 薄弱知识点 TOP-N
- 累计错误次数
- 近 7 天重复错误
- 近 30 天错误趋势
- 复习优先级建议

- B站搜索链接
- 复习笔记

## 15. PWA 与离线能力

- 提供 Web App Manifest、应用图标和 Service Worker
- 支持手机浏览器“添加到主屏幕”
- 缓存应用外壳和当前用户的常用数据
- 断网时可查看已缓存的错题和首页数据
- 退出账号时清理该用户的离线缓存，避免多用户数据串用
- 局域网 HTTP 访问时，部分浏览器不开放完整 PWA 安装和系统通知，可使用 `.ics` 日历导出

---

## 16. 性能与数据优化

- 错题库使用后端分页，避免一次加载全部错题
- 首页只加载最近 5 道错题和汇总数量
- 搜索、筛选、批量操作后自动刷新当前分页
- SQLite 增加用户、删除状态、学科状态、创建时间和复习计划索引
- AI 生成采用流式传输，长内容不需要等待完整返回
