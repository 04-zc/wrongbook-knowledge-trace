## 1. 系统概述

本系统是一套面向个人学习者的本地错题管理与知识溯源工具。系统通过 OCR、PDF/Word 解析、大模型分析、知识树、薄弱分析和复习计划，实现从“记录错题”到“定位薄弱知识点”的完整闭环。

核心目标：

```text
错题录入 → 知识点识别 → 知识溯源 → 薄弱分析 → 复习计划 → 掌握反馈
```

## 4. 用户账号与数据隔离

### 4.1 功能说明

- 用户名与密码仅支持英文字母和数字。
- 密码使用哈希存储。
- 每个用户拥有独立的学科、知识点、错题、复习记录和配置。
- 支持改名、修改密码、重置密码和删除账号。

## 9. 薄弱分析模块

### 9.1 薄弱指数算法

设当前筛选范围内的候选知识点集合为：

```text
Q = 知识点关联的未删除错题数
E = review_logs 中 result=0 的累计错误次数
D = Σ e^(-距离今天的天数 / 30)
R7 = 最近 7 天内 result=0 的次数

Qmax、Emax、Dmax、R7max 分别为候选知识点中对应指标的最大值

薄弱指数 =
    (Q / Qmax) × 0.4
  + (E / Emax) × 0.3
  + (D / Dmax) × 0.2
  + (R7 / R7max) × 0.1
```

最后乘以 10，并四舍五入保留 2 位小数，理论值域为 0～10。最大值不是固定 10；只有当某知识点在四个分项上都达到当前候选范围的最大值时，才会得到 10 分。

### 9.2 时间衰减

错误发生时间越早，权重越低：

```text
衰减值 = e^(-距离今天的天数 / 30)
```

`D` 会累加每一条错误复习记录的衰减值。若该知识点关联了错题，但完全没有复习记录，则回退使用错题创建时间计算衰减；只要存在复习记录，就不会触发该回退。

已删除错题不会进入薄弱分析。各分项最大值缺失或为 0 时按 1 处理，避免除零。

### 9.3 展示内容

- 薄弱知识点 TOP-N
- 累计错误次数
- 近 7 天重复错误
- 近 30 天错误趋势
- 复习优先级建议

## 15. PWA 与离线能力

- 提供 Web App Manifest、应用图标和 Service Worker
- 支持手机浏览器“添加到主屏幕”
- 缓存应用外壳和当前用户的常用数据
- 断网时可查看已缓存的错题和首页数据
- 退出账号时清理该用户的离线缓存，避免多用户数据串用
- 局域网 HTTP 访问时，部分浏览器不开放完整 PWA 安装和系统通知，可使用 `.ics` 日历导出

---

## 16. 性能与数据优化

- 错题库使用后端分页，避免一次加载全部错题
- 首页只加载最近 5 道错题和汇总数量
- 搜索、筛选、批量操作后自动刷新当前分页
- SQLite 增加用户、删除状态、学科状态、创建时间和复习计划索引
- AI 生成采用流式传输，长内容不需要等待完整返回

## 20. 实现边界与已知限制

- OCR 依赖本机安装 PaddleOCR 和 PaddlePaddle；未安装时，图片识别接口不可用，但手动录入和文字型文档导入仍可使用。
- 大模型功能依赖用户配置的 API Key；未配置时，知识点推荐、知识溯源和 AI 学习内容不可生成。
- PWA 的完整安装和系统通知依赖 `localhost` 或 HTTPS。普通局域网 HTTP 环境可以继续使用在线页面和 `.ics` 日历导出。
- 浏览器提醒只在页面打开时检查；当前版本没有后台 Web Push 服务。
- SQLite 适合单机个人使用，不适合多机或高并发部署。
- 上传接口当前通过随机文件名避免覆盖和路径注入，但尚未统一增加扩展名白名单、文件内容校验和请求体大小限制；部署到公网前应补充这些保护。
