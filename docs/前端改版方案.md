# 错题本前端改版方案

> 版本：v1（待确认）
> 范围：应用外壳、导航、登录页、首页、共用设计令牌、图标系统、图表配色、移动端与无障碍
> 目标：保持"安静、学术、工具化"的定位，提升专业度、可读性和答辩可讲性

## 1. 改版目标

1. 去掉 emoji 图标，统一使用 Lucide SVG 图标。
2. 从"蓝色主导"改为"中性灰底 + 单一蓝色强调色 + 红绿功能色"。
3. 重排页面布局：应用外壳、导航分组、页面骨架统一。
4. 重做登录页，作为改版后的视觉入口。
5. 达到 WCAG AA：正文对比度 4.5:1、可见焦点、触控目标不小于 44px。
6. 移动端做到 375px 不错乱、无横向滚动、底部安全区不遮挡内容。
7. 图表配色同步设计令牌，避免页面与图表两套色。

不做：深色模式、引入联网字体、改动后端接口和业务逻辑。

## 2. 设计令牌

### 2.1 颜色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f6f7f9` | 页面背景，中性灰 |
| `--surface` | `#ffffff` | 卡片、面板、弹窗 |
| `--surface-muted` | `#f2f4f7` | 次级面板、表头、禁用底 |
| `--border` | `#e4e7ec` | 分隔线、输入边框 |
| `--text` | `#111827` | 正文主色 |
| `--text-secondary` | `#4b5563` | 次级说明 |
| `--text-muted` | `#6b7280` | 弱化文字，仅用于 14px 及以上 |
| `--primary` | `#2563eb` | 主按钮、选中态、链接 |
| `--primary-hover` | `#1d4ed8` | 主按钮悬停 |
| `--primary-soft` | `#eff6ff` | 选中背景、提示底 |
| `--success` | `#059669` | 已掌握、成功 |
| `--warning` | `#b45309` | 警告文字；图表用 `#f59e0b` |
| `--danger` | `#dc2626` | 错误、删除 |
| `--focus` | `#2563eb` | 焦点环 |

对比度要求：正文与背景不小于 4.5:1；大号文字和图形不小于 3:1。`--text-muted` 不用于小号正文。

### 2.2 间距

统一 4px 节奏：`4 / 8 / 12 / 16 / 24 / 32 / 48`。

- 组件内边距：8 或 12
- 卡片内边距：16 或 24
- 区块间距：24 或 32
- 页面上下留白：32（桌面）、24（移动）

### 2.3 字号与行高

| 层级 | 字号 | 行高 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 24 | 1.3 | 各页 H2 |
| 区块标题 | 18 | 1.4 | 卡片标题 |
| 正文 | 14–16 | 1.6 | 题目、说明 |
| 辅助文字 | 12–13 | 1.5 | 标签、时间 |

不使用小于 12px 的文字。系统字体栈保持不变，保证中文显示可靠。

### 2.4 圆角与阴影

- 控件圆角 6px，卡片圆角 8px，不超过 8px。
- 只保留一套轻阴影：`0 1px 3px rgba(16, 24, 40, 0.08)`。
- 主按钮不用彩色阴影，避免"玩具感"。

## 3. 图标系统

使用 Lucide，本地文件 `static/vendor/lucide.min.js`，离线可用，和 echarts 的引入方式一致。

替换清单：

| 位置 | 现在 | 改为 |
| --- | --- | --- |
| 错题录入 | `📷 拍摄题目` | `camera` + 文字 |
| 错题录入 | `🖼 选择图片` | `image` + 文字 |
| 知识树 | `📁` 学科节点 | `folder` |
| 知识树 | `▸` 展开符 | `chevron-right`，展开时旋转 90 度 |
| 知识树 | `＋ 一级` | `plus` + 文字 |

图标规范：统一 1.75px 描边；图标尺寸 16 / 20 / 24；纯图标按钮必须有 `aria-label` 和 `title`；装饰性图标加 `aria-hidden="true"`。

## 4. 应用外壳与导航

### 4.1 桌面端

- 左侧固定侧栏，宽度 240px，背景白色，右侧 1px 边框。
- 侧栏顶部为品牌区：图标 + 产品名。
- 导航按用途分组，降低认知负担：
  - 学习：首页、错题录入、错题库、复习模式
  - 分析：薄弱分析、知识图谱、统计报表
  - 管理：学科设置、回收站、账号设置、模型与 OCR 配置
- 主内容区：顶部页面标题栏（标题 + 主操作按钮），下方内容最大宽度 1200px 居中。
- 每个页面只保留一个主操作按钮，其余按钮降级为次级样式。

### 4.2 移动端（375px 起）

- 顶部为精简栏：页面标题 + 菜单按钮。
- 底部固定导航 5 项：首页、录入、错题库、复习、更多。
- "更多"打开抽屉，放分析、报表、设置等其余入口。
- 底部导航加 `padding-bottom: env(safe-area-inset-bottom)`，内容区预留等高底部内边距，避免遮挡。
- 抽屉打开时锁滚动、焦点困在抽屉内、Esc 关闭。

## 5. 登录页重设计

桌面端采用左右分栏，整页铺满，不使用浮动卡片叠卡片：

- 左栏：品牌面。深蓝纯色背景，放产品名、一句话定位、三条能力要点。不放插画、不放装饰光斑。
- 右栏：表单面。白底居中，宽度 360–400px，标题"登录"、账号、密码、主按钮、辅助链接。

移动端：只保留表单面，品牌信息压缩为顶部一行标题。

表单要求：

- 输入框有可见 `label`，不只用 placeholder。
- 错误信息显示在字段下方，关联 `aria-describedby`。
- 主按钮在提交中禁用并显示"登录中…"。
- 支持密码管理器与粘贴。
- 键盘焦点顺序：账号 → 密码 → 登录 → 注册 → 重置。

## 6. 页面布局重排

统一页面骨架：页面标题栏 → 工具栏/筛选 → 内容区。所有页面复用同一套标题栏和卡片样式。

### 6.1 首页

按"先看状态，再动手"排序：

1. 4 个 KPI：总错题、未掌握、今日待复习、近 7 天仍错。
2. 今日复习：待复习题目列表 + "开始复习"主按钮。
3. 薄弱知识点 TOP3：带薄弱指数和"查看分析"。
4. 最近错题：最近 5 条，点击进详情。

### 6.2 错题录入

- 改成两栏：左侧表单，右侧实时预览（题干、图片、LaTeX 渲染）。
- 移动端改为单列，预览折叠在表单下方。
- 上传区改为虚线拖放区，含图标和"点击选择或拖拽图片"。

### 6.3 错题库

- 筛选栏固定在内容区顶部，滚动时保持可见。
- 表格列：题干、学科、知识点、状态、操作。状态用文字 + 颜色，不只靠颜色。
- 批量操作条改为选中后出现的浮动条，显示已选数量和操作按钮。
- 移动端：表格变卡片列表，每张卡显示题干、状态、操作。

### 6.4 薄弱分析与统计报表

- 图表统一使用设计令牌配色。
- 弱化网格线，突出数据系列；图例可点击。
- 图表下方给数据表或摘要，避免只靠颜色表达。
- 报表页主操作放"导出"按钮组，Word 为主、PDF 为次。

### 6.5 学科设置与知识树

- 桌面端两栏：左栏知识树，右栏知识点详情与操作。
- 树节点整行可点，展开箭头独立且不小于 44px 热区。
- 删除操作二次确认，危险色按钮放在对话框右侧。

## 7. 无障碍要求

- 所有交互元素有可见焦点环：2px 蓝色描边 + 2px 偏移。
- 颜色不作为唯一信息载体，状态同时有文字。
- 触控目标不小于 44×44px，图标小则扩大热区。
- 表单字段有 label、帮助文本和字段级错误。
- 弹窗打开时焦点进入弹窗，关闭后回到触发元素。
- 尊重 `prefers-reduced-motion`，动效只用于状态变化，不做装饰动画。

## 8. 图表配色同步

`static/app.js` 中硬编码颜色统一替换为令牌值：

| 语义 | 值 |
| --- | --- |
| 未掌握 | `#dc2626` |
| 已掌握 | `#059669` |
| 已复习 | `#f59e0b` |
| 已归档 | `#6b7280` |
| 主系列 | `#2563eb` |
| 对比系列 | `#7c3aed` |
| 警告系列 | `#b45309` |

薄弱指数档位同理：0–4 绿色、4–7 橙色、7–10 红色。

## 9. 实施步骤

1. `static/vendor/lucide.min.js` 新增本地图标库。
2. `static/style.css` 重写设计令牌、外壳、导航、页面骨架、表单与按钮样式。
3. `static/index.html` 重排外层结构、导航分组、登录页、首页卡片、三个 emoji 替换为 SVG 占位。
4. `static/app.js` 初始化 Lucide、同步图表配色、补焦点与抽屉交互。
5. 更新 `tools/README.md` 增加截图验收命令。
6. 更新 md 与 Word 文档中涉及界面描述的部分。

不改动后端接口、数据库结构、业务逻辑。

1. 现有回归全部通过：`e2e_check.py`、`test_fixes.py`、`test_round3.py`、`test_weak.py`、`test_integration.py`、`test_reports.py`、`test_pwa_offline.js`。

6. 页面中不再出现 emoji 结构性图标。
